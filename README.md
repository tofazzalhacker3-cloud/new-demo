# Tinker Time Printing and Engraving

One-page demo website for **Tinker Time Printing and Engraving** (Newbury, OH) — 3D printing, laser engraving, and laser cutting.

## Features

- Pure static site (HTML + CSS + JS) — no build step, no server needed
- Real Facebook page content and photos
- Fully responsive, modern design with animations
- Google Maps embed for the Newbury, OH location

## Deploy

- **Netlify:** drag & drop the folder, or import this repo with publish directory `.`
- **Local preview:** `python3 -m http.server 8099`
